# E-Learning System

## Project Overview
This project is an E-Learning System that allows instructors to create courses, 
students to enroll, and manage learning content.

## Technologies Used
Frontend:
- React.js
- Vite
- CSS

Backend:
- Node.js
- Express.js

Database:
- MySQL

## How to Run the Project

### Frontend
```bash
cd frontend
npm install
npm run dev
